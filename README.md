# E_Zavod
E_Zavod is a powerful production-flow simulator that connects directly to your SQL-based .bd database. It integrates advanced finance and operator management, tracking every detail—from skills to machine performance and unit movement time. More than software, it’s a complete ecosystem for total factory control.


## Project setup

To run the project locally, replicate the following sequence of steps:

``` bash
	python -m venv .venv
	source .venv/bin/activate (Windows: C:\> .venv\Scripts\activate.bat)
	pip install -r requirements.txt
```
